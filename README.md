# نور المسلم

تطبيق أندرويد إسلامي مجاني، يضم القرآن الكريم، المسبحة الإلكترونية، الأذكار والتلاوات.

## الحالة الحالية

هذه هي النسخة الأولى القابلة للتشغيل، وتحتوي على:

- واجهة عربية من اليمين إلى اليسار.
- شاشة رئيسية.
- مسبحة إلكترونية مع عداد وحفظ تلقائي للعدد.
- أذكار مختارة.
- قائمة القراء الأربعة.
- قسم القرآن مع بداية سورة الفاتحة.
- تنبيه اختياري للصلاة على النبي ﷺ.

## التشغيل

افتح المشروع في Android Studio Hedgehog أو أحدث، ثم شغّل مهمة `app` على جهاز Android أو محاكي.

> ستتم إضافة نص القرآن الكامل والتلاوات المرخصة في المرحلة التالية من خلال مصادر موثوقة، مع احترام حقوق النشر ودقة النص القرآني.
